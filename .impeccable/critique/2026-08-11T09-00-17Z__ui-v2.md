## Design Specificity Verdict

Two products in one shell. The Trade tab (SetupCheck, ZoneRead, engine read) is deeply authored: research verdicts (68.4%, n=19) encoded as layout, two tallies never summed, absence always given a reason. The shell around it — Heat radar, Tape, Map, the 9-tab IA — is generic dashboard furniture, and the product's actual spine (the five-state machine) renders at 14px inside a rail panel on one of nine tabs. Specificity is inverted: maximum authorship at the leaf, template thinking at the root.

Deterministic scan: 7 CLI findings (4 side-tab accent borders — live DOM shows they resolve to a single brass hue, so the old "four competing accents" audit finding is fixed; 1 transition:width on a 4px meter fill; 2 overused-font, of which 'Roboto Mono' is a false positive). In-page detector: 59 findings — 49 undersized text (9–10px: LOOK HERE, LIVE, column headers, % cells), 4 zero-offset glows, 2 contrast fails (#141a22 on brass 4.4:1; #6b7482 on #f7f8fa). Zero @media rules, zero :focus/:focus-visible rules across 19 interactive elements, zero prefers-reduced-motion with two infinite animations running. Console and network clean; tabular-nums correctly set on all 7 price elements.

## What's Working

1. **Epistemic honesty as a design system, enforced in code.** SetupCheck's TickState never collapses "couldn't check" into "false"; Chain.builtAt null = "unknown, never fresh"; ZoneRead says "no put wall in the chain profile" instead of omitting the row. Non-negotiable #1 is genuinely kept.
2. **Color-semantics discipline.** theme.ts: brass=structure, green/red=direction only — stop renders muted, NEUTRAL never paints red, light-palette deviations carry measured contrast comments.
3. **The two-tally refusal** — scored trigger and unscored context kept as separate counts, never summed; the sell mirror labeled rejected-by-data.
4. **"Changes if breaks X / or loses Y"** — the purest operate-mode sentence on screen.

## Priority Issues

- **[P0] The state machine is invisible at shell level.** The product is WAITING→ARMED→TRIGGERED→IN TRADE→OUT; that state exists only inside Trade→SetupCheck. From any other tab or window, an ARM event changes nothing glanceable. document.title never changes. Fix: persistent machine strip beside the AnswerBand — five states, current lit, one advancing number per state (distance-to-d3 / candles-left + ref_high / entry+stop / VWAP milestone / exit_why) — and mirror state into document.title.
- **[P1] Nine-tab IA contradicts the product.** Tape duplicates Trade's chart at lower fidelity; Map re-renders levels the chart already draws; Heat feeds no decision in the machine; Proto self-describes as deletable; default tab is Heat, not the product. Fix: Trade becomes the default and effectively the app; Chain+OI Flow fold into one evidence surface; Events becomes a drawer; retire Tape/Map; delete Proto on verdict.
- **[P1] Accessibility is zero, measured.** 0 @media, 0 focus rules on 19/19 interactive elements, 0 reduced-motion with pulse-live + glow-pulse infinite; no tablist semantics, no landmarks; rule-delete is tabIndex −1 (keyboard-unreachable); 49 elements under 11px. Fix: focus-visible ring, tablist roles, reduced-motion guard, raise the micro-label floor.
- **[P2] Frame discipline leaks outside the chart.** Glance bar shows NIFTY 24,530 (futures) while OI Flow LTP shows 24,454 (index) — 76 points apart simultaneously, no frame label. Fix: FUT/IDX badges on every price column outside the chart.
- **[P2] The idle state is undesigned; Events churns.** WAITING shows six competing zones; WALL KHISKI flip-flops 24400↔24450 six times through the FOCUS filter. Fix: hysteresis/collapse oscillating pairs; design WAITING as the primary composition.

## Persona Red Flags

**Alex (power user):** no keyboard path to anything (only Enter in two inputs); reload resets to Heat/NIFTY; the one number he'd glance for in WAITING — distance to d3 — isn't printed anywhere; 11-column OI table forces horizontal reading for what the OI strip says in one line.

**Sam (accessibility):** cannot see focus anywhere; cannot reach Heat-cell tooltips or pressure-bucket notes by keyboard; cannot delete a custom rule; no landmarks/headings across nine tabs; 9–10px type pervasive. Direction is arrow+color (good) — failures are focus and reach, not hue.

## Single-Screen Distillation

Keep, ranked: (1) a state-machine strip — five states, current lit, one advancing number (doesn't exist today; it is the product); (2) the ContractChart with σ bands, ref candle, ref_high, stop; (3) SetupCheck's trigger block — 3 rows + "Todna hai > X / Stop < Y" (context rows behind a disclosure); (4) the honesty banners, unconditioned; (5) price + "Changes if breaks/loses" as one line; (6) one flow line (the existing crl mark, not the table).

Cut: Heat (scan surface feeding no decision — the glance bar's three index cells already say which index moves), Tape (second lower-fidelity render of the same session), Map (third render of levels), Events (drawer — top items already reach the chart as STORY balloons), Validate (drawer summoned at TRIGGERED), OI Flow table (drawer), Proto (delete on verdict), replay transport (behind a control; scrubbing is analysis-mode).

End state: most of the week the screen says, calmly, "WAITING — d3 24,509.6, price 24,530, gap 20.4 — nothing to do," and 1–2×/week becomes impossible to miss.

## Questions to Consider

1. If the product is the five-state machine, why is its current state the smallest text on the ninth-most-prominent surface? What if the machine were the screen and every chart a drill-down?
2. Is frame discipline a chart-overlay rule or a product rule? If the latter, every number outside the chart needs a frame badge.
3. For a single known operator, would an empty, designed "no tape" state be more honest than believable fake candles behind a disclaimer banner?
