# Eval Rubric — TapeMap redesign (design mode)

Weighted score = 0.35·Design + 0.30·Originality + 0.25·Craft + 0.10·Functionality.
Pass threshold: 7.5.

### Design Quality (weight: 0.35)
Visual hierarchy, typographic discipline, color restraint with semantic state
colors, composition that guides the eye, density appropriate to a professional
instrument. Would a designer respect it? Would a trader trust it?

### Originality (weight: 0.30)
A genuine compositional idea — not a stacked-panel dashboard reskin, not any
of the five rejected directions in spec.md. "Would this win a design award?"
Does it have one memorable, defensible signature element?

### Craft (weight: 0.25)
Alignment, spacing rhythm, label collision handling at event clusters, edge
cases (long messages, dense minutes), consistent radii/strokes, tabular
numerals, no clipped text, coherent at 1280×720.

### Functionality (weight: 0.10)
Loads /api/data, renders real Jul 17 numbers, the five glance-questions in
spec.md are answerable, a time affordance exists. (Half-broken but stunning
beats complete but ugly — yet it must at least render.)
