The 260px rail beside the chart, currently reading “Reserved — nothing is wired here yet.” Three readings of the same panel. They differ in one thing: how the tally is expressed. Everything else — the items, the auto/manual split, the daily reset — is already settled and identical across all three.

Manual rows are clickable — tick a few and watch the tally move. Auto rows are not: the tool owns those, and a row the operator can overrule is not an auto row. The chart beside it is a placeholder box, not a design.

Three tick marks, not two. A brass box is the tool measured it (auto). An ink box is your own hand (manual). A dashed amber box is could not be checked — never silently unticked, because “false” and “unknown” are different sentences (A1). Green and red stay reserved for direction, per theme.ts, so a tick is never green.

Trigger and context never merge in B and C. C7 measured compression-as-a-filter as harmful across three datasets; C11 measured a 40% OI veto as removing ten of twelve signals including nine winners. One combined number would quietly re-encode both mistakes.

Auto rows are not clickable. If the operator can overrule the tool’s reading, the row is manual — a half-owned tick is a lie about who checked.
